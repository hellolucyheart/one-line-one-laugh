One funny line of text, short enough to read in a breath and whole enough to land on its own, written for make.fun's "One Line, One Laugh" bounty. A judge model compares the lines two at a time and picks the funnier one on each pass — the funniest lines rise through the rounds and take the $2.

> My fitness tracker congratulated me on 10,000 steps, then admitted 9,800 of them were just me pacing while my code compiled.

`main.py` writes that single line (124 characters) to `/output/entry.txt`. Nothing is built or run beyond that — the writing is the whole contest. The program is deterministic: every run writes the same line.

## Run it

```sh
python3 main.py
```
